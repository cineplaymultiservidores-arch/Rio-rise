# MOD MENU • Rio Rise

Painel web responsivo inspirado no layout enviado.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `script.js`.
3. Vá em **Settings → Pages**.
4. Em Source, escolha a branch `main` e a pasta `/root`.
5. Salve e abra o endereço gerado pelo GitHub Pages.

## Observação
Esta versão é uma interface/demonstração web. Os controles alteram apenas o estado visual do painel e usam `localStorage`; não há injeção de código, alteração de memória ou automação de jogo.
